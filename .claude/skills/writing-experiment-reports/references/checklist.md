# Pre-publish checklist

Run every item before calling a report done.

## Voice and form

- [ ] Takeaway is a single capitalized sentence in a blockquote at the top, with no label.
- [ ] No em dashes or en dashes anywhere (grep for them).
- [ ] First person, in the moment. No "so far", "as we will see", "the key turned out".
- [ ] No "What's next" section and no forward links to later experiments.
- [ ] Motivation is in the author's own voice, not a quote of repo policy.
- [ ] No "see the intro / glossary / methodology" pointer blocks.
- [ ] Tight: no sentence that carries neither information nor voice.

## Substance

- [ ] Method opens with the hypothesis and its risk, then the approach.
- [ ] Every headline number traces to a row in the results ledger.
- [ ] Single-seed numbers are flagged as preliminary where they appear.
- [ ] Results lead with a table AND a paragraph that interprets it.
- [ ] Discussion interprets the mechanism, states limits, and says what it rules in or out.
- [ ] Negative results are stated honestly, not softened, and say what they rule out.
- [ ] Figures are relative links into `figures/` and committed.
- [ ] Configuration is copy-pasteable text, never a screenshot.
- [ ] "Reproduce this" has exact, runnable commands.
- [ ] Method states only what is specific to this experiment; shared setup is not recited.

## Series

- [ ] One row added to the experiments index; it names the finding and marks negative results.
- [ ] References link backward and outward only, never forward.
